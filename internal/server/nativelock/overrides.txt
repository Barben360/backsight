# The native lock's deliberate departures from the pinned Hindsight image.
# scripts/native-lock.sh resolves the image's set with each of these in
# place of the image's version (or added, when the image lacks it), checks
# the resolved lock holds each at exactly this version, and records each in
# both locks' headers ("# override: name==version (image: version)").
# Every other package stays the image's own. One per line:
# "name==version: reason". Drop a line once the pinned image ships that
# version or a newer one: the script refuses an override the image has
# caught up with.
#
# The pinned image (Hindsight 1.2.0) ships pyasn1 0.6.4, which has
# published security advisories. The Docker runtime still runs the image's
# version. filelock stays the image's 3.20.3: its fix (4.2.1) is above
# litellm's filelock<4.0 (litellm 1.104.0 in the image, and still in
# 1.106.6, the latest release on 2026-11-03).
