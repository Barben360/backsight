# The native lock's deliberate departures from the pinned Hindsight image.
# scripts/native-lock.sh resolves the image's set with each of these in
# place of the image's version (or added, when the image lacks it), checks
# the resolved lock holds each at exactly this version, and records each in
# both locks' headers ("# override: name==version (image: version)").
# Every other package stays the image's own. One per line:
# "name==version: reason". Drop a line once the pinned image ships that
# version or a newer one: the script refuses an override the image has
# caught up with.
#
# The pinned image (Hindsight 1.2.0) ships pyasn1 0.6.4, which has
# published security advisories. The Docker runtime still runs the image's
# version. filelock 4.2.1 is forced past litellm 1.104.0's filelock<4.0
# (FORCED in scripts/native-lock.sh): litellm imports it in its proxy CLI
# only, and huggingface-hub (model downloads) uses it too, both through an
# API 4.x keeps; litellm 1.109.1 itself accepts filelock<5. soupsieve 4.x
# drops 2.x's handling of template and iframe contents as separate
# documents (CSS selectors only); beautifulsoup4 asks for soupsieve>1.2.
# dnspython 2.9.2 is a patch release of the image's 2.9.0. OpenTelemetry
# releases its packages as one set: opentelemetry-sdk and
# opentelemetry-semantic-conventions pin opentelemetry-api exactly, and the
# exporters and instrumentations pin each other, so opentelemetry-api's fix
# (1.45.2) moves the whole set to its patch release (1.45.2/0.66b2), whose
# only other change is a metric cardinality limit (past 2000 series, a
# metric's new series fold into one otel.metric.overflow series; nothing
# fails).
