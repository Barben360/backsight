Whose activity is this?

The scope line under the top bar, in every state of block 8. The switch is a pair of links (?machines=this, ?machines=all) that keep the page, the window and the project filter.

This PC, the default. Other PCs share on this server, so the switch shows how many.

All PCs: the scope reads “all PCs on this server (4)”. One PC sent nothing for 9 days and one document was ignored: each says so.

All PCs, “Which PCs” open: short machine id, system and first-seen date only.

All PCs with a project filter: the filter applies to this PC only, and the scope line says the other PCs are counted whole.

This PC’s sharing is off: “all PCs” is not offered. The link goes to Machines on System, which says what to change.

Only this PC shares on this server: no switch, the scope line is the one shipped today.

A client in remote mode, all PCs: the server is another machine.

The server host, all PCs: the same switch and the same figures; the address is local and says so.

Memory server not answering, all PCs: the other PCs’ figures are the ones fetched last, and the line says when.

The CLI disclosure: the command carries --machines all only when all PCs is selected (this PC is the default).

The flag in the terminal

every stats view
--machines this
The default: this PC’s activity, as today.
--machines all
This PC’s activity added to the figures the other PCs on this server share: “all PCs on this server (4)”. Project filters apply to this PC only.
API
/api/v1/<view>?machines=all returns what stats <view> --machines all --json returns.
