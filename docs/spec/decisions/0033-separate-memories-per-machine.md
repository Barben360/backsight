# 0033 — One memory per machine; no sharing between the work and personal machines

- **Date**: 2026-10-24
- **Status**: accepted
- **Decided by**: author (Q4)

## Decision
Each of the author's machines keeps its own server and bank. M6 adopts the work machine as a separate install; no merge, export or sync between the two memories is built. Remote mode (0024) stays for several machines that the user chooses to point at one server.

## Why
The work machine holds employer content; the personal machine must not receive it, and the reverse.
