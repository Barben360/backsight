# 0004 — Onboarding is a first-class goal

- **Date**: 2026-10-23
- **Status**: accepted
- **Decided by**: author

## Decision
A frictionless first install is a primary success criterion, on par with memory quality. Every install step must be explainable, previewable (dry-run plan) and recoverable. The author wants "the most perfect and frictionless project on the first iteration".
