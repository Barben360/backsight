# 0049 — Local server: rendered compose, minimal install, bank template, provider check (M1 block 1)

- **Date**: 2026-10-24
- **Status**: accepted (agent, under the author's delegation; open to veto)
- **Decided by**: agent, from the reference stack's compose file, Hindsight 1.1.0's OpenAPI and config.py

## Decision
- **Images pinned in the binary** by index digest (multi-arch), tag kept for readability: `ghcr.io/vectorize-io/hindsight:1.1.0@sha256:50311d02b4d5d2b7c5242bd336edf8735df8374eaad496a92f49c83b37d2aa06`, `pgvector/pgvector:pg18@sha256:2358fcba361ed2233a5ed81b5fe4ca779ccb304120ce531a3bf51c0ed7e2bc11`. `server.digest` in config overrides the Hindsight digest only (empty = the binary's pin).
- **`server render`** writes `<compose_dir>/compose.yaml` (0644, header "generated by backsight, edit compose.override.yaml") and `.env` (0600). Compose project `backsight`, so it never collides with another stack's containers or volumes. Services:
  - `db`: shm 1 GB, healthcheck, named volume `pg_data`;
  - `hindsight`: depends on a healthy `db`, named volume `hf_cache` for models.
- **Ports**: API on the `server.url` port and UI on the new `server.ui_port` (default 9999). Both are bound to `127.0.0.1`, or to `network.bind_ip` under private exposure.
- **`.env`**:
  - database URL and password;
  - built-in API-key tenant (`api_key`);
  - control plane: API key and access key (`ui_key`);
  - LLM: provider, model, key and base URL;
  - `HINDSIGHT_API_LLM_OUTPUT_LANGUAGE=English`: server-side enforcement of 0039, on top of the strategy text;
  - embeddings `onnx` (multilingual-e5-small default) and reranker `local` mmarco-mMiniLMv2-L12 with `MAX_CANDIDATES=60` (the reference stack's measured CPU cap);
  - LLM timeout 300 s;
  - a stable `WORKER_ID=backsight-<hostname>`.
  The English preset is refused until its env is verified on a real image ("not available yet").
- **Secrets**:
  - `api_key`, `ui_key` and `db_password` are generated by `server install` when absent (32 random bytes, base64url).
  - `llm_api_key` is set by the user with `secret set llm_api_key` (no echo, or `--from-env`/`--from-file`).
  - `secret list` shows names and whether each is set, never values.
- **`server install`** (minimal, no wizard until M4), idempotent:
  - config written if absent, from flags `--api-port`, `--ui-port`, `--provider`, `--model`, `--base-url`;
  - secrets generated, then render;
  - `docker compose pull`, then `up -d`;
  - wait for `/health` (up to 10 min on first start: models download);
  - `bank apply`, then the provider check.
  Each step is reported, and `--plan` lists the steps without acting.
- **`server start|stop|status`**: `docker compose -p backsight up -d | stop | ps` plus health and version. The binary drives `docker compose` (CLI v2) and never the Docker API.
- **`bank apply`**: `PUT /banks/{id}` (name, mission), then `PATCH /banks/{id}/config` with only the keys backsight owns:
  - `retain_strategies.conversation` and `.document`: English facts rule, durability rules, absolute dates, exact identifiers, nothing for plans or hypotheses, label each fact with its kind; chunk 30 000;
  - `retain_default_strategy`;
  - `entity_labels`: the `kind` group, `tag: true`;
  - `entities_allow_free_form`, `enable_observations`, `observations_mission`;
  - `default_observation_scopes`: `[["project:*"]]`.
  The SHA-256 of the canonical JSON of that set is recorded as `state.bank_config_hash`. Re-applying the same template sends nothing. Other keys on the bank are left alone.
- **Provider check** (`server llm check`, also run by install): `POST /memories/dry-run-extract` with the `conversation` strategy on a fixed short bilingual sample.
  - It passes when at least one fact is well formed (non-empty text and a known fact type) and in English.
  - "In English" is deterministic: no fact contains more than one word from a short French stopword list.
  - Failure exits 20 with the provider's error or the offending fact.

## Why
Generated files make every install identical and diffable. A separate project name lets the author's dev install run beside the reference stack (ports 18888/19999). A key-subset hash keeps `bank apply` additive and drift detectable. The dry-run endpoint proves auth, model, structured output and language without storing anything.
