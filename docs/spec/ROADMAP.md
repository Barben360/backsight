Target ≈ 15–20 USD/month at equal quality. **Built 2026-11-08, release pending**: C1–C9 in backsight PRs 231–239 (https://github.com/Barben360/backsight/pull/231 to https://github.com/Barben360/backsight/pull/239), one per issue under the epic https://github.com/Barben360/backsight/issues/220, merged in sequence; differences in `decisions/INDEX.md` ("0083, as built").
