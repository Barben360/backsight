**Pre-release.** Linux amd64 is tested; the Linux arm64, macOS and Windows binaries are built but not tested.

Update from any earlier v0.1 with `backsight update apply`: it takes a verified backup first and rolls back if a step fails. Then restart Claude Code (or run `/reload-plugins`), so the memory tools and the skills use the new binary too. New install: see below. No migration, and nothing changes on an install that stays on Docker.

## What changed

**A native runtime for the memory server, on Linux** (`backsight guide native-runtime`)

- `server.runtime = "native"` runs the memory server without Docker: Hindsight 1.1.0 from PyPI in a Python environment whose every package is checked against a hash this release pins (uv 0.13.1, Python 3.11.17), and the PostgreSQL that pg0 ships, both as systemd user units (`<project>-db.service`, `<project>-server.service`). Docker stays the default.
- `backsight setup --runtime native` installs a new memory on it. Backups, `backup verify` (in a throwaway database), restore, `server upgrade` (with rollback to the previous environment), uninstall and doctor all work on it.
- Guards against losing the memory silently: the database starts only on the instance backsight created (a missing, empty or foreign data directory is refused, with `backsight restore` as the way out), a postgres running outside the unit is stopped, never reused, and `fsync` is checked on after every start. After a refused start, restore moves the refused database aside instead of deleting it.

**Move an existing memory between Docker and native**

- `backsight server runtime switch native|docker` downloads what the target needs, stops the API, takes a verified backup, restores it into the other runtime and compares the two databases (row counts, every primary key, the banks and backsight's own documents) before anything else changes. Only an exact match switches `server.runtime`; any failure, or Ctrl-C, puts the previous runtime back as it was. Clients keep the same address and need nothing. Recall is compared too and reported (the two runtimes' rerankers can order near-ties differently), never blocking.
- The runtime you left keeps its data until `backsight server runtime clean`, which shows what it deletes and asks first. doctor reports what was kept and a switch cut off part way.

**Changed output** (for scripts and agents that read it)
- Backup manifests gain `runtime` and `hindsight_version`; an archive from one runtime restores into the other at the same Hindsight version.
- New JSON fields: `units_changed` (`server render`), `moved_aside` (`restore`), `stopped_strays` (`backup verify`), `runtime` and `runtime_switch` (`stats`). Docker installs print the same fields as before otherwise.
- New doctor checks on native installs (`native-*`, `runtime-switch`); a Docker install's check list is unchanged.
- The instruction set stays v10.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/Barben360/backsight/main/scripts/install.sh | sh
backsight setup
```

Requirements as for v0.1.15-m6: Linux amd64, Docker with Compose v2 usable without `sudo`, Claude Code 2.1.309 or newer, an LLM provider key, about 6 GB of free disk. For the native runtime instead (`backsight setup --runtime native`): no Docker, a systemd user session from a login of your user, lingering on (`loginctl enable-linger`), about 3.5 GB of free disk. To join the memory of a PC already set up, install the binary the same way, then run `backsight connect --token-file <file>` instead of `backsight setup`. To put the memory server on another machine instead, run `backsight server install --ssh user@host` from a PC with OpenSSH's client; `backsight guide several-pcs` covers both.

## Known limits

- Tested on Linux amd64 only. The native runtime runs on Linux x86_64 only, is not tested on WSL, serves this PC only (no `server expose --private`, no server-only host) and has no web UI.
- On native, PostgreSQL is 18.1 with pgvector 0.8.5, where the Docker image runs 18.6 with 0.8.7; `backup verify` runs in the runtime that will restore.
- The switch's comparison covers row counts, keys, banks and backsight's documents, not every column's content.
- A plain `doctor` shows the size of what a switch kept for a day after the switch; `doctor --json` measures it again.
- Claude cannot run `/reload-plugins`: after an update from the session, you type it.
- A LAN address carries the API key in clear; a tailnet address encrypts it.
- The shared part of a session continued on two PCs may be stored twice.
- A session part never confirmed after 24 hours is reported (doctor's `replace-unconfirmed`), not sent again automatically.
