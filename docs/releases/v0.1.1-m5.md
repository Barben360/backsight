**Pre-release.** The second public pre-release of backsight. Linux amd64 is tested; the Linux arm64, macOS and Windows binaries are built but not tested.

Update from v0.1.0-m5 with `backsight update apply`: it takes a verified backup first and rolls back if a step fails. New install: see below.

## What changed

**Security and privacy**
- Redaction catches more secret shapes before anything reaches your LLM provider: age keys (including backsight's own backup key), PGP private keys, netrc passwords, Docker logins and auth, Slack and Discord webhooks, more token prefixes, Azure keys and SAS signatures. It also removes the exact values stored in backsight's own secret files. `docs/privacy.md` lists what is caught and what is not.
- Built with Go 1.26.10, which fixes the standard-library vulnerabilities of v0.1.0-m5. CI now runs govulncheck and Dependabot watches the dependencies.
- A `.backsight.toml` committed in a repository you clone can no longer choose the project your sessions are stored under or pull other projects into recall. It can still turn recording off (`retain = false`).
- Third-party license notices ship in every archive and in the binary: `backsight version --licenses`.

**Setup**
- Setup tells you when Docker refuses your user (the `docker` group) or is not running, also on Docker 26.
- After a rejected LLM key: `backsight secret set llm_api_key`, then `backsight setup --resume` works.
- The download (about 2.3 GB on the first install) shows its progress; `setup --reconfigure` asks the questions again.
- Setup creates the backup key, and uninstall removes the anonymous volume and tells how to remove the images.
- Coding agents: paste the prompt at the top of the README, or run `backsight guide agent-guide`.
- Ollama on Linux: the server can reach an Ollama on the host (see the install guide for how to expose it safely).

**Memory quality**
- Each subagent's report is filed under the repository it worked in, not the one the session started in.
- The same rule runs silently on the main conversation and is measured; it is switched on once it is shown to be right.
- `backsight retain reattribute` moves already-stored memories to the right project, and the daily job does the moves that cost no extraction.
- A purged session stays purged: if an older backsight on another machine writes to it again, it is purged again within 15 minutes, and what that machine wrote after the purge is kept.
- Notes stored by Claude go to the current project; the shared pool takes only what is named for it. `backsight memory notes` lists recent notes.
- Doctor watches for drift: wrong project labels left to move, the shared pool's noise growing, recreated purged documents.
- Repositories you work on together can be searched together (`recall.families`, off by default for now).

**Daily use**
- The session line now reads like `🧠 backsight · 🗂️ <project> · memory on`, with one emoji per state.
- DeepSeek's prices and model name (`deepseek-flash`) follow its pricing of 2026-10-26; the spending cap counts at peak price, so it never under-counts.
- The docs cover every level: what it costs, prerequisites, a glossary, every `config.toml` key, and how a prompt is handled.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/Barben360/backsight/main/scripts/install.sh | sh
backsight setup
```

Requirements as for v0.1.0-m5: Linux amd64, Docker with Compose v2 usable without `sudo`, Claude Code 2.1.309 or newer, an LLM provider key, about 6 GB of free disk.

## Known limits

- Tested on Linux amd64 only.
- The new project rule is applied to subagent reports only; on the main conversation it is measured but not applied yet.
- Project families are off by default until they are measured on real use.
- A purge again costs a little LLM work on the server (consolidation); with the `claude-code` provider or a remote server it waits for `backsight retain purge-again --allow-subscription`.

Report problems at https://github.com/Barben360/backsight/issues, after reading the diagnostic `backsight report` prints. Report vulnerabilities privately, as https://github.com/Barben360/backsight/blob/main/SECURITY.md describes.
