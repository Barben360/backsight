**Pre-release.** A small release on top of v0.1.2-m5. Linux amd64 is tested; the Linux arm64, macOS and Windows binaries are built but not tested.

Update from v0.1.2-m5, v0.1.1-m5 or v0.1.0-m5 with `backsight update apply`: it takes a verified backup first, updates the plugin and rolls back if a step fails. Then restart Claude Code (or run `/reload-plugins`). New install: see below.

## What changed

**Citations**
- Claude now cites a memory as `🧠 From memory (<project>) — …`, shorter than `From Hindsight memory`. The instruction set moves to v4.
- `backsight stats` counts both wordings as exact credits, so a reply in the old form, or a `CLAUDE.md` that still asks for it, is not lost. A plain "from memory" without the 🧠 counts as a free use, as before.

**Setup**
- The default model for `openai` is now `gpt-6-luna`, replacing `gpt-5.4-mini`, and its price is known: setup's backfill estimate and `backsight stats` show its cost. An existing install keeps its model: change `llm.model` in `config.toml` to switch.

**README**
- Says up front that searching the memory (recall at each prompt, `memory_search`, `backsight search`) runs on your machine, with no LLM call: it is free and sends nothing out.
- A shorter cost table, with GPT-6 Luna: $0.04 per session, $4 a month at 5 sessions a day.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/Barben360/backsight/main/scripts/install.sh | sh
backsight setup
```

Requirements as for v0.1.2-m5: Linux amd64, Docker with Compose v2 usable without `sudo`, Claude Code 2.1.309 or newer, an LLM provider key, about 6 GB of free disk.

## Known limits

- Tested on Linux amd64 only.
- The new project rule is applied to subagent reports only; on the main conversation it is measured but not applied yet.
- Project families stay off by default: a replay on real prompts showed no change yet.
- A purge again costs a little LLM work on the server (consolidation); with the `claude-code` provider or a remote server it waits for `backsight retain purge-again --allow-subscription`.

Report problems at https://github.com/Barben360/backsight/issues, after reading the diagnostic `backsight report` prints. Report vulnerabilities privately, as https://github.com/Barben360/backsight/blob/main/SECURITY.md describes.
