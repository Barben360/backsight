**Pre-release.** Linux amd64 is tested; Windows amd64 is tested in CI, with no new run on a Windows PC for this release. The Linux arm64 and macOS binaries are built but not tested.

Update from any earlier v0.1 with `backsight update apply`: it takes a verified backup first and rolls back if a step fails. Then restart a running dashboard (Ctrl+C, then `backsight dashboard`). New install: see below. No server change, and no change to the metrics index.

## What changed

**The dashboard has its design**

- The pages follow the new design: a verdict on four questions, tiles with their change from the previous period, charts with a "Show as a table" view, and a plain sentence wherever a number is missing or a page is busy, updating or expired (`docs/dashboard.md`, "When a number is missing").
- Numbers and dates are written in your browser's language; the words stay in English.
- Theme (system, light or dark), developer mode and a one-minute auto-refresh are in the Preferences menu. The server writes the theme into the page, so it opens in the right colours with no flash.
- The pages work without scripts. Only the Copy buttons need them: without scripts the command is plain text you can select, and if the browser refuses the clipboard the button selects the command and says "Selected: press Ctrl+C".
- Keyboard and screen-reader support: a "Skip to content" link, a logical Tab order, a table behind every chart (the small tile trends have a spoken summary), text contrast of at least 4.5:1 in both themes, forced-colours support and touch-sized controls on small screens.
- Faster loads: when nothing changed in your feedback files in the last 2 seconds, a page no longer reads them again to refresh its numbers. This applies only when the feedback folder is on a local disk, not a network or synced folder; while a session is writing, they are still read in full. On generated test data, a refresh with nothing new took 2 ms instead of 93 ms.
- The Definitions page and `backsight stats defs` suggested a command that does not exist to lower the context budget; they now name the setting, `recall.session_budget_chars` under `[recall]`.

## Install

On Linux:

```sh
curl -fsSL https://raw.githubusercontent.com/Barben360/backsight/main/scripts/install.sh | sh
backsight setup
```

On Windows x86_64, in PowerShell:

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://raw.githubusercontent.com/Barben360/backsight/main/scripts/install.ps1 | iex"
backsight setup
```

Requirements as for v0.1.22-m7. On Windows, Claude Code must find Git Bash: if Git for Windows is portable or installed in a place of your own, set `CLAUDE_CODE_GIT_BASH_PATH` to its `bin\bash.exe` (doctor's `git-bash` check gives the command).

## Known limits

- Windows: WSL is not tested, and Windows on Arm has no binary. The native runtime is the only runtime there (`server runtime switch` is refused), it serves this PC only and has no web UI. The server starts with your logon, not at boot.
- On Windows, `backsight server status` keeps showing the server's last refusal while it is stopped, until a start passes the check.
- backsight's `.exe` files are not code-signed: SmartScreen or Smart App Control may warn about them. The install script checks the release signature before it runs anything.
- Dashboard: the project filter takes a typed name, not a pick from a list (the Projects page lists the names); the Projects list cannot be sorted; the context card names the session budget rather than showing its value.
- A new install reads "learning" for its first week, and some numbers read "too few" until enough prompts and turns accumulate.
- Extraction cost needs prices set under `[llm]` in the config file. The server reports token counts for all PCs together.
- On native, PostgreSQL is 18.1 with pgvector 0.8.5, where the Docker image runs 18.6 with 0.8.7; `backup verify` runs in the runtime that will restore.
- Claude cannot run `/reload-plugins`: after an update from the session, you type it.
- A LAN address carries the API key in clear; a tailnet address encrypts it.
- The shared part of a session continued on two PCs may be stored twice.
- A session part never confirmed after 24 hours is reported (doctor's `replace-unconfirmed`), not sent again automatically.
